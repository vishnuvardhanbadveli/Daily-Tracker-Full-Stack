# Daily Tracker

A full-stack personal habit tracking application.

## Tech Stack

Frontend:
- React
- Vite
- Tailwind CSS

Backend:
- Node.js
- Express.js

Database:
- MySQL

## Features

- Create daily tasks
- Edit and delete tasks
- Track daily completion
- Monthly progress analytics
- Heatmap visualization
- Responsive design
